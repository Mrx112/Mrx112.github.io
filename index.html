Bukan sekadar showcase — ini hasil lab yang bisa diuji langsung dari browser. Setiap lab berisi topologi, konfigurasi perangkat, dan skenario pengujian yang dapat dijalankan sendiri: kirim paket, putus link, lihat failover, sampai simulasi serangan.

LAB_01 LIVE

HomeCloud Link

Home Server ↔ Warehouse AI Cluster

Simulasi konektivitas antara home server dan cluster AI di gudang, lengkap dengan berkas konfigurasi Packet Tracer. Topologi bisa dijalankan interaktif: animasi aliran paket (kuning = paket, hijau = balasan, merah = drop), CLI diagnostik, uji failover dengan memutus link antena, hingga modul pengujian keamanan.

  • Routing & desain topologi
  • VLAN 802.1Q & trunking
  • Link antena point-to-point + failover ISP
  • Uji keamanan: flood/DoS, brute force, port scan
